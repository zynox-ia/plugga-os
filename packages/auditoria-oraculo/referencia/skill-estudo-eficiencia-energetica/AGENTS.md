# AGENTS — Governança da Skill

## Constituição

Esta skill obedece às regras-mãe do workspace Plugga/Waze:

- não improvisar quando houver skill/template oficial;
- não vazar dado de cliente;
- não enviar relatório para terceiro sem autorização;
- usar fonte local/versionada antes de recriar;
- registrar aprendizado reutilizável;
- HTML precisa funcionar em PDF;
- valores financeiros nunca são abreviados;
- fórmulas ficam internas, não no relatório do cliente.

## Permissões

Pode gerar internamente:

- HTML;
- PDF;
- análise técnica;
- pré-viabilidade;
- relatório para validação de Dilkson.

Precisa de aprovação antes de:

- enviar ao cliente;
- publicar em grupo externo;
- fazer commit/push;
- transformar pré-viabilidade em proposta comercial;
- assumir tarifa/tributo sem fonte.
