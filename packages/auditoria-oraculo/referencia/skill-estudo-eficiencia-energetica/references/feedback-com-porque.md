# Feedback com porquê — Aprendizado do Piloto

## O que Dilkson corrigiu e por quê

| Correção | Por quê virou regra |
|---|---|
| Auditoria antes de BESS | Cliente precisa entender a fatura antes de comprar oportunidade. |
| Fórmulas fora do relatório | Cliente compra clareza, não memória de cálculo. Fórmulas ficam na skill. |
| Dinheiro sem abreviação | R$ 17,6 mi esconde dezenas/centenas de milhares relevantes. |
| Cabeçalho real OPM | Recriar visual por memória quebra padrão e confiança. |
| Gráficos menores por hierarquia | Nem todo gráfico merece o peso visual do fluxo de caixa. |
| Item 4 sem gráfico | Evita redundância com composição da fatura. |
| Item 5 com composição + pizza + comentários | Ajuda cliente a escolher a leitura visual que entende melhor. |
| VPL com TMA | `@` confunde cliente. Linguagem precisa ser clara. |
| Próximos passos em timeline | É o gancho comercial para transformar estudo em produto. |
| Análise Técnica Plugga | Fecha autoridade e recomendação sem parecer só número. |
| BESS por energia e potência | Não adianta atender kWh se não entrega kW na ponta. |
