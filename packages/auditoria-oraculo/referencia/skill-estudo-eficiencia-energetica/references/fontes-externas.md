# Fontes externas e validações

## Fontes necessárias por relatório

- Fatura completa da distribuidora.
- REH/tarifa homologada vigente no mês.
- Base tributária/benefício fiscal aplicável.
- Bandeira tarifária vigente.
- Memória de massa 15 min.
- 12 faturas para histórico.
- Preço de mesa Mercado Livre para UF/submercado.
- Datasheet do BESS quando diferente do padrão.
- Cotação para projeto básico, projeto executivo, EPC, operação e manutenção.

## Regra de verdade externa

Se a fonte não foi consultada, o relatório deve dizer “validar” ou “pendente”. Não inventar tarifa, tributo, benefício ou regra regulatória.
