# Triage labels

Mapeamento dos papéis canônicos das skills para os rótulos do Linear:

| Papel | Rótulo no Linear | Significado |
|---|---|---|
| `needs-triage` | `needs-triage` | Aguarda avaliação do mantenedor |
| `needs-info` | `needs-info` | Aguarda informações de quem relatou |
| `ready-for-agent` | `ready-for-agent` | Definida e pronta para implementação por agente |
| `ready-for-human` | `ready-for-human` | Requer implementação humana |
| `wontfix` | `wontfix` | Não será atendida |

Ao usar um papel de triagem, aplique o rótulo correspondente. A criação de rótulos e a alteração de issues seguem a autorização para integrações externas definida em `AGENTS.md`.
