# Issue tracker

O Linear é a fonte da verdade para projetos, issues e dependências da Plugga OS.

- Use a integração Linear configurada. Determine a equipe e o projeto pela issue ou pela solicitação; se houver dúvida, pergunte ao André.
- Leia a issue, os critérios de aceite, os comentários e as relações de bloqueio antes de implementar.
- Em `to-tickets` e `to-spec`, registre o resultado esperado e os critérios de aceite na issue do Linear. Preserve as dependências nas relações nativas do tracker.
- Siga diretamente da issue para o código. Conforme `AGENTS.md`, não use milestones, specs, OpenSpec nem Spec Kit.
- Alterações em integrações externas exigem autorização explícita do André, conforme `AGENTS.md`. Este setup registra apenas a configuração local.
